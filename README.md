# Countrivia 🌍

Countrivia is a fun, interactive mobile application designed to help you master world geography. Learn flags and capitals through a structured level-based progression system and test your knowledge with engaging quizzes.

## ✨ Features

- **Level-Based Progression**: 10 countries per level. Master one level to unlock the next!
- **Interactive Quizzes**: Test your memory with flag-to-country and country-to-capital questions.
- **Learn Mode**: Flip through country cards to study flags and capitals before the quiz.
- **Dark Mode**: Sleek, high-contrast interface support.
- **Progress Tracking**: Keep track of your mastery levels for every country.
- **Offline First**: All data is bundled locally for a seamless experience without an internet connection.
- **Sound Effects**: Auditory feedback for correct and incorrect answers.

## 🚀 Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/countrivia.git
   cd countrivia
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the project:
   ```bash
   npm start
   ```

## 📱 Running on Mobile

### Expo Go

1. Install the **Expo Go** app on your iOS or Android device.
2. Scan the QR code displayed in your terminal after running `npm start`.

### Standalone Build (EAS)

Refer to the `deployment_guide.md` for detailed instructions on creating standalone APK/IPA files using EAS Build.
